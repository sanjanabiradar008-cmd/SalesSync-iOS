# SalesSync-iOS

A native iOS and iPadOS executive sales dashboard engineered to visualize end-to-end inbound customer acquisition pipelines driven by automated backend systems like n8n or Make.com.

This application explicitly demonstrates high-value commercial software workflows—tracking revenue potential, intent scoring metrics, and automated scheduling funnels natively on mobile interfaces.

## ⚡ Multi-Stage Automation Pipeline Architecture
- **Real-Time Data Streams:** Engineered to display real-time background status payloads passing through remote n8n server endpoints.
- **Claude Intent Scoring Integration:** Maps layout states dynamically based on backend AI categorization loops processing incoming corporate entities.
- **Auto-Calendar Sync Logic:** Utilizes state indicators (@State) to update application interface colors automatically upon successful appointment scheduling confirmation.

## 🛠️ Technical Stack
- **Language:** Swift 5.x
- **Framework:** SwiftUI
- **Environment:** Swift Playgrounds / Xcode
- **Automation Pipeline:** Integrated via n8n Conditional Routing Engine
